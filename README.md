Um dashboard de controle financeiro moderno, responsivo e inteligente desenvolvido com **Next.js (App Router)**, **TypeScript** e **Recharts**. O projeto simula análises automatizadas de gastos através de uma API Serverless integrada no Next.js.

![FinAI Dashboard Preview](./public/og-image.png)

---

## Funcionalidades

- **Dashboard Interativo:** Cards de saldo total, entradas e saídas atualizados em tempo real.
- **Gráficos Responsivos:**
  - Gráfico de Rosca/Pizza por Categoria com porcentagens dinâmicas (`Recharts`).
  - Evolução mensal de receitas vs. despesas.
- **Insights de IA Integrados:** Análise preditiva e recomendações automáticas de economia baseadas nos padrões de consumo.
- **Gestão Completa de Transações (CRUD):** Tabela para adicionar, editar, filtrar e remover movimentações financeiras.
- **Dark Mode Automático:** Suporte nativo a temas claros e escuros via variáveis CSS e Tailwind.

---

## Tecnologias Utilizadas

- **Framework:** [Next.js](https://nextjs.org/) (App Router & Serverless API Routes)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/) (Tipagem estrita)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Visualização de Dados:** [Recharts](https://recharts.org/)
- **Componentes de UI:** [Shadcn/ui](https://ui.shadcn.com/) / Lucide Icons
- **Gerenciamento de Estado:** React Context API + Custom Hooks
